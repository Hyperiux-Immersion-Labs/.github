# Security Policy
 
## Supported Versions
| Version | Supported |
|---------|-----------|
| Latest  | ✅        |
| < 1.0   | ❌        |
 
## Reporting a Vulnerability
Do not report security vulnerabilities via public GitHub issues.
 
Email security@hyperiux.com with:
- Description of the vulnerability
- Steps to reproduce
- Potential impact
 
We aim to respond within 48 hours.
